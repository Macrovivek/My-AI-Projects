Project 1 · AI-Powered EDI File Generation

Benefits Platform Claude API GitHub Copilot XML / EDI 834 Jira MCP April 2026

📌 Problem

Benefits engineers manually built EDI 834 XML files for insurance carriers — a slow, error-prone process requiring deep domain expertise. With 20,000+ existing XML files and peak volumes of 10–20 new builds per day, the process was a critical bottleneck.

🏗️ AI Solution Architecture

  • Jira Agent: Connects to Jira, pulls carrier specs & group IDs from tickets
  • Spec Parser: LLM reads Excel/PDF/Word specs, extracts field mappings & usage flags
  • XML Generator: Claude API produces DSL-based XML using 20K+ file library as reference
  • Auto Validator: Iterative LLM loop checks for missing segments, incorrect IDs, format errors
  • Auto Delivery: Generated file is attached to carrier contract, exported & verified automatically
  • GitHub Copilot UI: Engineers trigger and adjust pipeline through the enterprise-approved Copilot interface

Project 2 · AI TVL Converter — Legacy-to-Modern Migration

Migration Program Pay Compare UI LLM API CC → EC Migration REST API Dec 2025

📌 Problem

The client had 1,000+ customers on a legacy Classic Calc (CC) engine (Delphi, 1990s) needing migration to Enhanced Calc (EC, .NET). Engineers manually translated complex TVL (embedded SQL-like) logic — 4–6 hours per expression — making a 3+ year migration timeline unsustainable.

🏗️ AI Solution Capabilities

  • Automated Conversion: AI-powered Customs Converter integrated directly into Pay Compare UI
  • EC-compliant Output: Returns validated JSON output conforming to Enhanced Calc schema
  • Domain-Aware LLM: Handles domain-specific rules, patterns, and edge cases automatically
  • Dual API Endpoints: One for conversion, one for business-friendly step-by-step explanation
  • Seamless Integration: Fully accessible through REST API integrated with Pay Compare
  • Continuous Refinement: Feedback loop for ongoing prompt tuning and model improvement

Legacy Migration Claude Sonnet 4.5 GitHub Copilot Agents Jira MCP ECE Log Analysis Dec 2025

📌 Problem

Calculation variances between Classic Calc and Enhanced Calc were reviewed manually — a slow, expert-dependent process that delayed customer migrations. Engineers dug through ECE logs, Jira tickets, and attachments, taking 6–12 hours per variance with inconsistent results.

🏗️ Agentic AI Architecture

  • Orchestrator Agent: GitHub Copilot Agent takes Jira ticket # and drives the full workflow
  • Jira MCP Tools: Fetches ticket info, downloads attachments, surfaces related historical tickets
  • ECE Log Analyzer: Calc log analysis and backtracking through Claude Sonnet 4.5
  • CCE Analyzer: Identifies code pointers, function calls, and branching logic mismatches
  • Excel Parser: Processes variance analysis spreadsheets automatically
  • Consolidated RCA Report: AI generates clear, business-friendly root cause explanation
