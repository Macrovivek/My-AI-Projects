## 📂 Detailed Case Studies

### 1. 📄 AI-Powered EDI File Generation (Benefits Platform)
- **Problem:** Benefits engineers manually built EDI 834 XML files for insurance carriers — a slow, error-prone process requiring deep domain expertise. With 20,000+ existing XML files and peak volumes of 10–20 new builds per day, it was a major bottleneck.
- **AI Solution:** 6-step automated pipeline:
  1. Pulls Jira ticket metadata & carrier specs
  2. Parses specs (Excel/PDF/Word) via LLM
  3. Generates XML templates referencing a 20K+ file library via Claude API
  4. Iterative LLM validation catches syntax & segment errors
  5. Automatic platform attach and export verification
  6. Optional triggers via enterprise-approved GitHub Copilot interface
- **Result:** Cut build time from 20 min–2 hrs down to ~15 min (**85% time savings**).

### 2. ⚙️ AI TVL Converter (Legacy-to-Modern Migration)
- **Problem:** Migrating 1,000+ customers from a legacy calculation engine (1990s Delphi) to a modern engine (.NET). Manual translation of complex embedded SQL-like TVL expressions took 4–6 hours per expression, pacing for a 3+ year bottleneck.
- **AI Solution:** AI-powered converter integrated directly into the Pay Compare UI and exposed via REST API endpoints. Includes an automated explanation endpoint translating complex expressions into plain-language business logic.
- **Result:** Reduced engineering effort to 30 mins per expression (**87.5% time savings**, 80% accuracy achieved).

### 3. 🔍 AI Variance Analysis & Root Cause Automation
- **Problem:** Calculation variances between legacy and modern calculation engines were reviewed manually — requiring 6–12 hours per variance ticket to inspect ECE logs, paycheck data, and scattered Jira tickets.
- **AI Solution:** Agentic workflow leveraging GitHub Copilot Agents, Claude Sonnet 4.5, and Jira MCP. Automatically backtracks calculation logs, analyzes discrepancies, categorizes root causes, and identifies related historical tickets.
- **Result:** Slashed investigation time to ≤3 hrs (**75% time reduction**, targeting 90% accuracy).
